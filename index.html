3 รูปแบบการเชื่อมต่อระบบ

เลือกรูปแบบการเชื่อมต่อที่ตอบโจทย์การทำงานของหน่วยงานท่าน

📤

1. ส่งข้อมูลเข้า Fondue

เชื่อมระบบแจ้งเหตุหรือ Application ของหน่วยงาน เพื่อส่งเรื่องแจ้งใหม่เข้ามาดำเนินการต่อในระบบ Traffy Fondue

  • new-issue ส่งเรื่องแจ้งใหม่พร้อมพิกัดและรูป
  • update-issue อัปเดตสถานะและแนบรูปผลงาน
  • star บันทึกคะแนนความพึงพอใจ
  • comment ส่งข้อความแชต/SMS ถึงผู้แจ้ง
  • join-forward เชิญร่วม & ส่งต่อเคส
📥

2. ขอข้อมูลจาก Fondue

ดึงรายการเรื่องแจ้ง พิกัด ภาพถ่าย และข้อมูลโครงสร้างหน่วยงานไปแสดงผลบน Dashboard หรือระบบภายในของท่าน

  • get-issues ดึงรายการเรื่องแจ้งพร้อมตัวกรอง
  • get-issue ดึงประวัติและข้อมูลเชิงลึกรายเคส
  • download-issues Export ข้อมูลเป็น CSV
  • search-org ค้นหาหน่วยงานจากชื่อ
  • get-org-list / get-type-list ผังองค์กร & หมวดหมู่
🔔

3. Real-time Webhooks

ระบบ Traffy Fondue ส่งข้อมูลแจ้งเตือนไปยัง Server ปลายทางของท่านทันทีเมื่อมีเหตุการณ์เกิดขึ้น โดยไม่หักโควต้า

  • POST (New Issue) แจ้งเตือนเมื่อมีเคสใหม่เข้ามา
  • PATCH (Status Update) แจ้งเมื่อเจ้าหน้าที่อัปเดตงาน
  • Non-quota ไม่นับรอบ Credit Balance
Getting Started

ขั้นตอนการขอใช้งาน API

เริ่มต้นเชื่อมต่อกับ Traffy Fondue Exchange API ง่ายๆ ใน 4 ขั้นตอน

1

กรอกแบบฟอร์ม

ลงทะเบียนข้อมูลหน่วยงานและผู้ประสานงานผ่าน Google Form เพื่อขอเปิดบัญชี Exchange API

2

รับข้อมูลทางอีเมล

ทีมงานจะส่ง Username, Password, โควต้าการใช้งาน และเอกสาร PDF ให้ทางอีเมลที่ระบุ

3

ขอรับ JWT Token

นำ Username & Password ไปเรียก API /get-auth/v1 เพื่อรับ Bearer Token

4

เริ่มเชื่อมต่อ API

นำ Token ที่ได้รับใส่ใน Header Authorization: Bearer แล้วเรียกใช้ API ที่ต้องการได้ทันที
