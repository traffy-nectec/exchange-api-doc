3 รูปแบบการเชื่อมต่อระบบ

เลือกรูปแบบการเชื่อมต่อที่เหมาะสมกับความต้องการของหน่วยงาน

📤

1. ส่งข้อมูลเข้า Fondue

เชื่อมระบบแจ้งเหตุหรือ Application ของหน่วยงาน เพื่อส่งเรื่องแจ้งใหม่เข้ามาดำเนินการต่อในระบบ Traffy Fondue

  • new-issue ส่งเรื่องแจ้งใหม่พร้อมพิกัดและรูป
  • update-issue อัปเดตสถานะและแนบรูปผลงาน
  • star บันทึกคะแนนความพึงพอใจ
  • comment ส่งข้อความแชต/SMS ถึงผู้แจ้ง
📥

2. ขอข้อมูลจาก Fondue

ดึงรายการเรื่องแจ้ง พิกัด ภาพถ่าย และข้อมูลโครงสร้างหน่วยงานไปแสดงผลบน Dashboard หรือระบบภายในของท่าน

  • get-issues ดึงรายการเรื่องแจ้งพร้อมตัวกรอง
  • get-issue ดึงประวัติและข้อมูลเชิงลึกรายเคส
  • download-issues Export ข้อมูลเป็น CSV
  • get-org-list ผังโครงสร้างหน่วยงานในสังกัด
🔔

3. Real-time Webhooks

ระบบ Traffy Fondue ส่งข้อมูลแจ้งเตือนไปยัง Server ปลายทางของท่านทันทีเมื่อมีเหตุการณ์เกิดขึ้น โดยไม่หักโควต้า

  • POST (New Issue) แจ้งเตือนเมื่อมีเคสใหม่เข้ามา
  • PATCH (Status Update) แจ้งเมื่อเจ้าหน้าที่อัปเดตงาน
  • Non-quota ไม่นับรอบ Credit Balance
Getting Started

ขั้นตอนการขอใช้งาน API

เริ่มต้นเชื่อมต่อกับ Traffy Fondue Exchange API ง่ายๆ ใน 4 ขั้นตอน

1

กรอกแบบฟอร์ม

ลงทะเบียนข้อมูลหน่วยงานและผู้ประสานงานผ่าน Google Form เพื่อขอเปิดบัญชี Exchange API

2

รับข้อมูลทางอีเมล

ทีมงานจะส่ง Username, Password, โควต้าการใช้งาน และเอกสาร PDF ให้ทางอีเมลที่ระบุ

3

ขอรับ JWT Token

นำ Username & Password ไปเรียก API /get-auth/v1 เพื่อรับ Bearer Token

4

เริ่มเชื่อมต่อ API

นำ Token ที่ได้รับใส่ใน Header Authorization: Bearer แล้วเรียกใช้ API ที่ต้องการได้ทันที

API Reference

เอกสารสเปก API ฉบับสมบูรณ์

Base URL: https://publicapi.traffy.in.th/exchange-api

🔍
POST /get-auth/v1 ขอ JWT Bearer Token
🔑 Auth: User / Pass

ใช้สำหรับส่ง user และ pass ที่ได้รับทาง Email เพื่อแลกรับ JWT Bearer Token สำหรับนำไปใช้กับ API ตัวอื่นๆ

Request Body Parameters
ParameterTypeคำอธิบาย
userREQstringชื่อผู้ใช้งานที่ได้รับทางอีเมล
passREQstringรหัสผ่านที่ได้รับทางอีเมล
cURL Example 
curl -X POST "https://publicapi.traffy.in.th/exchange-api/get-auth/v1" \
  -H "Content-Type: application/json" \
  -d '{"user": "YOUR_USER", "pass": "YOUR_PASS"}'
Response (200 OK) 
{
  "status": "success",
  "credit_balance": 820,
  "quota_limit": 1000,
  "results": [{
    "token": "eyJhbGciOiJIUzI1Ni...",
    "expire_timestamp": "2026-08-31 23:59:59"
  }]
}
POST /get-issues/v1 ดึงรายการเรื่องแจ้งในหน่วยงาน
🛡️ Header: Bearer Token

ดึงรายการเรื่องแจ้งที่หน่วยงานได้รับ พร้อมตัวกรองช่วงวันที่, สถานะ, ประเภทปัญหา, คำค้นหา และการแบ่งหน้า (Pagination)

Request Body Parameters
ParameterTypeคำอธิบาย
start_dateOPTstringวันที่เริ่มต้น YYYY-MM-DD
end_dateOPTstringวันที่สิ้นสุด YYYY-MM-DD
stateOPTarray[str]กรองสถานะ เช่น ["รอรับเรื่อง", "กำลังดำเนินการ"]
offset / limitOPTintการแบ่งหน้า (limit ไม่เกิน 1,000)
cURL Example 
curl -X POST "https://publicapi.traffy.in.th/exchange-api/get-issues/v1" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"start_date": "2026-08-01", "limit": 20}'
POST /get-issue/v1 ดึงรายละเอียดเชิงลึกของเรื่องแจ้ง
🛡️ Header: Bearer Token

ดึงข้อมูลเชิงลึกและประวัติ Timeline การดำเนินงานทั้งหมดของเรื่องแจ้งตาม ticket_id หรือ client_ticket_id

Request Body Parameters
ParameterTypeคำอธิบาย
ticket_idREQ*stringรหัสเรื่องแจ้ง Fondue (เช่น 2026-ABCDEF)
client_ticket_idREQ*stringหรือรหัสเรื่องแจ้งของหน่วยงานภายนอก
cURL Example 
curl -X POST "https://publicapi.traffy.in.th/exchange-api/get-issue/v1" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"ticket_id": "2026-ABCDEF"}'
POST /new-issue/v1 ส่งเรื่องแจ้งใหม่เข้า Fondue
🛡️ Header: Bearer Token

ส่งเรื่องแจ้งเหตุใหม่จากระบบภายนอกเข้าสู่ระบบ Traffy Fondue พร้อมระบุพิกัด GPS, รูปภาพ และประเภทปัญหา

Request Body Parameters
ParameterTypeคำอธิบาย
descriptionREQstringข้อความรายละเอียดปัญหา
latitude / longitudeREQnumberพิกัด GPS (WGS84)
typeOPTstringชื่อประเภทปัญหา (เช่น ถนน, ทางเท้า)
photoOPTarray[str]Array URL รูปภาพประกอบ
client_ticket_idOPTstringรหัสอ้างอิงเรื่องแจ้งในระบบของท่าน
cURL Example 
curl -X POST "https://publicapi.traffy.in.th/exchange-api/new-issue/v1" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "description": "พบฝาท่อชำรุด",
    "latitude": 13.7563,
    "longitude": 100.5018,
    "type": "ถนน"
  }'
POST /update-issue/v1 อัปเดตสถานะเรื่องแจ้ง
🛡️ Header: Bearer Token

ปรับปรุงสถานะการดำเนินงานของเรื่องแจ้ง (เช่น รับเรื่อง, กำลังทำ, เสร็จสิ้น) พร้อมแนบรูปภาพหลังแก้ไข หรือไฟล์เอกสารรายงาน

Request Body Parameters
ParameterTypeคำอธิบาย
ticket_idREQ*stringรหัสเรื่องแจ้ง Fondue
stateREQstringสถานะใหม่ เช่น กำลังดำเนินการ, เสร็จสิ้น
noteOPTstringข้อความบันทึกการปฏิบัติงาน
photoOPTarray[str]Array URL รูปภาพหลังการแก้ไข
cURL Example 
curl -X POST "https://publicapi.traffy.in.th/exchange-api/update-issue/v1" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "ticket_id": "2026-ABCDEF",
    "state": "เสร็จสิ้น",
    "note": "ซ่อมแซมเรียบร้อยแล้ว"
  }'
WEBHOOK POST / PATCH to Client URL Real-time Push Notification
⚡ Non-Quota

ระบบ Traffy Fondue ส่งข้อมูลไปยัง Server ของหน่วยงานทันทีเมื่อมีเรื่องแจ้งใหม่ (POST) หรือเมื่อเจ้าหน้าที่มีการอัปเดตสถานะ (PATCH)

Events Supported
  • New Issue Event (POST): ส่งข้อมูลเคส พิกัด และรูปภาพทันทีที่รับแจ้ง
  • Status Update Event (PATCH): ส่งสถานะล่าสุดและข้อความบันทึกของเจ้าหน้าที่
