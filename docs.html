การยืนยันตัวตน (Authentication)

แลกเปลี่ยน Username และ Password ที่ได้รับจากทีมงานเพื่อรับ JWT Bearer Token

POST /get-auth/v1 1. ขอ JWT Bearer Token
🔑 Auth: User / Pass

นำ user และ pass ที่ได้รับทาง Email มาแลกรับ JWT (JSON Web Token) เพื่อใช้เป็น Header Authorization: Bearer <token> ยืนยันตัวตนใน API อื่นๆ เกือบทั้งหมด

  • ห้ามเผยแพร่ user และ pass สู่สาธารณะเด็ดขาด เช่น ห้ามฝังไว้ในเว็บไซต์หรือ mobile app เพราะอาจถูก inspect หรือ sniffing ดูได้ — ให้ขอ token จาก server เท่านั้น
  • หาก credit_balance ลดลงเร็วผิดปกติ ให้รีบติดต่อทีมงาน Traffy ทันที ที่ LINE @fonduehelp เพื่อตรวจสอบและเปลี่ยนรหัสใหม่
  • JWT token ถูกตั้งเวลาให้หมดอายุ โปรดตรวจสอบจาก expire_timestamp ที่ได้รับมาพร้อมกับ token
Request Body (JSON)
ชื่อ คำอธิบาย ตัวอย่าง REQUIRED?
userstring ชื่อผู้ใช้งานของ account ที่ได้รับแจ้งในเอกสารการใช้งาน — ห้ามเผยแพร่สู่สาธารณะเด็ดขาด YOUR_USERNAME REQUIRED
passstring รหัสผ่านของ account ที่ได้รับแจ้งในเอกสารการใช้งาน — ห้ามเผยแพร่สู่สาธารณะเด็ดขาด YOUR_PASSWORD REQUIRED

curl -X POST "https://publicapi.traffy.in.th/exchange-api/get-auth/v1" \

  -d '{
    "user": "YOUR_USERNAME",
    "pass": "YOUR_PASSWORD"
  }'

ส่งความคิดเห็นหลังการประเมิน หรือส่งข้อความแชตไปยังผู้แจ้ง

Request Body (JSON)
Parameter Type คำอธิบาย ตัวอย่าง REQUIRED?
comment string ข้อความความคิดเห็น หรือข้อความสนทนา ขอบคุณสำหรับการแจ้งเหตุครับ REQUIRED
ticket_id / client_ticket_id string ระบุอย่างใดอย่างหนึ่ง 2026-GYDHMT REQUIRED*
comment_type string ค่าที่ส่งมาจะถูกส่งต่อไปยัง API ภายในตามที่ได้รับ โค้ดในไฟล์นี้ตรวจสอบเป็นพิเศษเฉพาะค่า comment เท่านั้น (ค่าอื่นๆ และ default หากไม่ส่งมา ขึ้นกับ API ภายในปลายทาง) comment OPTIONAL
base64comment string ข้อความความคิดเห็นแบบ Base64 4Kaq4Kaw... OPTIONAL
noti_reporter / noti_staff bool รับค่าไว้ แต่ในไฟล์นี้ไม่ได้ถูกส่งต่อหรือใช้งานที่ใดเลย (ปัจจุบันไม่มีผลต่อการทำงาน) true OPTIONAL

Running out of API usage quota โควต้าประจำเดือนหมด ติดต่อขอเพิ่มโควต้าผ่านทาง LINE: @fonduehelp
